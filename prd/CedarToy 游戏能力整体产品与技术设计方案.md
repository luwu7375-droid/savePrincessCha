CedarToy 游戏能力整体产品与技术设计方案                                                                
                                                                                                         
  执行摘要                                                                                               
                                                                                                         
  基于对 savePrincessCha 现有架构和 CedarToy 平台的深入调查，本方案将游戏能力设计为 Cha                  
  生活体验的自然延伸，而非独立功能模块。核心原则：                                                       
                                                                                                         
  1. 真实发生原则：游戏事件必须基于实际 MCP 调用，不允许模型编造                                         
  2. 记忆隔离原则：游戏记录 ≠ 长期记忆，需要过滤和转化                                                   
  3. 自主性边界：Cha 可以自主玩游戏，但有明确的时间、成本和用户控制边界                                  
  4. 信息架构一致性：复用现有的日记、活动记录、状态系统，不创建平行系统                                  
                                                                                                         
  关键发现：                                                                                             
  - ✅ CedarToy 提供了完整的 MCP Server 接口，可直接集成                                                 
  - ✅ savePrincessCha 已有成熟的日记系统、活动记录系统和自主行为框架                                    
  - ⚠️ 星露谷集成是占位符，与 CedarToy 可统一为游戏活动系统                                              
  - ⚠️ 需要新建游戏会话管理、状态追踪和记忆过滤机制

  1.3 与新需求冲突的部分                                                                                 
  冲突点: Chat 是私密空间                                                                                
  原因: 不应该成为游戏监控台                                                                             
  解决方案: 游戏状态仅轻量提示，完整界面在 Playground/手机                                               
  ────────────────────────────────────────                                                               
  冲突点: 日记污染风险                                                                                   
  原因: 游戏操作日志不应该进入日记                                                                       
  解决方案: 过滤规则：仅 changed 非空且通过 checker 的游戏事件可候选                                     
  ────────────────────────────────────────                                                               
  冲突点: 星露谷独立系统                                                                                 
  原因: 当前是占位符，未来可能重复实现                                                                   
  解决方案: 废弃独立实现，统一为游戏活动系统                                                             
  ────────────────────────────────────────                                                               
  冲突点: 自主性无限运行                                                                                 
  原因: 没有明确的游戏时长和预算限制                                                                     
  解决方案: 新增配置项：game_session_max_duration, game_daily_token_cap

  2.3 推荐集成方式                                                                                       
                                                                                                         
  通过 Supabase Edge Function 作为 MCP 客户端                                                            
                                                                                                         
  // supabase/functions/game-proxy/index.ts                                                              
  import { MCPClient } from '@modelcontextprotocol/sdk';                                                 
                                                                                                         
  const client = new MCPClient({                                                                         
    serverUrl: 'https://toy.cedarstar.org/{token}',                                                      
    timeout: 30000                                                                                       
  });                                                                                                    
                                                                                                         
  // 列出游戏                                                                                            
  const games = await client.callTool('list_games', {});                                                 
                                                                                                         
  // 执行动作                                                                                            
  const result = await client.callTool('play', {                                                         
    game: '海龟汤',                                                                                      
    action: 'ask',                                                                                       
    params: { question: '是否与人有关？' }                                                               
  });

  三、完整产品设计                                                                                       
                                                                                                         
  3.1 用户旅程地图                                                                                       
                                                                                                         
  旅程 A：发现 Cha 正在玩游戏                                                                            
                                                                                                         
  【场景 1】用户打开 Home 页                                                                             
      ↓                                                                                                  
  Home 页顶部状态卡片                                                                                    
      ├─ 显示："Cha 正在玩海龟汤 🎮"                                                                     
      ├─ 轻量信息：游戏名称 + 状态图标                                                                   
      └─ 点击 → 跳转到游戏详情页（Playground）                                                           
                                                                                                         
  【场景 2】用户在 Chat 页                                                                               
      ↓                                                                                                  
  Chat 顶部轻状态栏                                                                                      
      ├─ 显示：小 Cha 头像 + "正在玩海龟汤…"                                                             
      ├─ 不影响聊天主流程                                                                                
      └─ 点击 → 进入游戏围观页                                                                           
                                                                                                         
  【场景 3】Cha 主动在聊天中提起                                                                         
      ↓                                                                                                  
  Chat 消息流                                                                                            
      ├─ Cha："我刚刚在玩海龟汤，猜到了一个谜题！想看看吗？"                                             
      ├─ 消息类型：type='game_event'                                                                     
      ├─ 附带游戏链接卡片                                                                                
      └─ 用户点击 → 查看游戏回放                                                                         
                                                                                                         
  旅程 B：用户主动让 Cha 玩游戏                                                                          
                                                                                                         
  用户在 Chat 说："去玩个游戏吧"                                                                         
      ↓                                                                                                  
  Route Detection 识别为 'game_invitation'                                                               
      ↓                                                                                                  
  Cha 回复："想玩什么呢？"                                                                               
      ├─ 选项 1：推荐游戏（基于偏好）                                                                    
      ├─ 选项 2：随机选择                                                                                
      └─ 选项 3：让我自己选                                                                              
                                                                                                         
      ↓ 用户选择或 Cha 自主选择                                                                          
  调用 game-proxy Edge Function                                                                          
      ├─ list_games()                                                                                    
      ├─ 过滤适合当前心情/时间的游戏                                                                     
      └─ 选择游戏（如"AI钓鱼"）                                                                          
                                                                                                         
      ↓                                                                                                  
  创建游戏会话                                                                                           
      ├─ 写入 game_sessions 表                                                                           
      ├─ 调用 play(game='AI钓鱼', action='start')                                                        
      ├─ 返回初始状态                                                                                    
      └─ Cha 在 Chat 中说："好，我去钓鱼了"                                                              
                                                                                                         
      ↓                                                                                                  
  用户可选择：                                                                                           
      ├─ 继续聊天（游戏后台进行）                                                                        
      ├─ 点击"陪她玩" → 进入游戏页面                                                                     
      └─ 什么都不做（Cha 自主玩）                                                                        
                                                                                                         
  旅程 C：围观和参与                                                                                     
                                                                                                         
  用户点击"查看 Cha 正在玩的游戏"                                                                        
      ↓                                                                                                  
  进入 Playground > 游戏中心 > 当前会话                                                                  
      ├─ 显示游戏界面                                                                                    
      ├─ 历史动作列表（时间线）                                                                          
      ├─ 当前状态（如钓鱼次数、金币）                                                                    
      └─ 操作选项                                                                                        
                                                                                                         
      ↓ 用户可以：                                                                                       
  选项 1：纯围观                                                                                         
      ├─ 实时刷新 Cha 的操作                                                                             
      └─ 看到她的想法（"这次会不会钓到传说鱼？"）                                                        
                                                                                                         
  选项 2：给建议                                                                                         
      ├─ 在 Chat 中说："试试用高级鱼竿"                                                                  
      └─ Cha 收到建议，决定是否采纳                                                                      
                                                                                                         
  选项 3：共同决策                                                                                       
      ├─ Cha 遇到选择时主动问："买鱼竿还是卖鱼？"                                                        
      └─ 用户投票或决策                                                                                  
                                                                                                         
  选项 4：接管                                                                                           
      ├─ 用户点击"我来玩"                                                                                
      ├─ 游戏控制权转移                                                                                  
      └─ Cha 进入观看模式                                                                                
                                                                                                         
  旅程 D：离开和返回                                                                                     
                                                                                                         
  用户离开游戏页面                                                                                       
      ↓                                                                                                  
  游戏会话进入"后台模式"                                                                                 
      ├─ Cha 继续有限度地玩                                                                              
      ├─ 每隔 N 分钟执行一次动作                                                                         
      ├─ 受配置限制：max_background_turns=10                                                             
      └─ 达到限制后暂停，等待用户返回                                                                    
                                                                                                         
      ↓ 期间发生重要事件                                                                                 
  Cha 主动联系用户                                                                                       
      ├─ 场景 1：猜到谜题 → Chat 中发消息："猜到了！"                                                    
      ├─ 场景 2：遇到困难 → "这个谜题好难，能帮我想想吗？"                                               
      ├─ 场景 3：资源耗尽 → "钱不够了，要不要卖些鱼？"                                                   
      └─ 场景 4：游戏结束 → "钓鱼结束了，今天钓了 20 条鱼"                                               
                                                                                                         
      ↓ 用户返回                                                                                         
  查看游戏结果                                                                                           
      ├─ 位置 1：Playground > 游戏历史                                                                   
      ├─ 位置 2：Cha 的手机 > 游戏 app > 历史                                                            
      └─ 位置 3：Couple 空间 > 时间线（如果标记为重要）                                                  
                                                                                                         
  旅程 E：沉淀和回忆                                                                                     
                                                                                                         
  游戏会话结束                                                                                           
      ↓                                                                                                  
  自动生成活动摘要                                                                                       
      ├─ 写入 cha_activity_log（action_type='game_play'）                                                
      ├─ 包含：游戏名称、时长、关键事件、结果                                                            
      └─ 不自动进入日记                                                                                  
                                                                                                         
      ↓ Cha 在晚上或用户明确要求时                                                                       
  生成第一人称日记                                                                                       
      ├─ source_type: 'game'                                                                             
      ├─ source_boundary: 'shared_activity'（如果用户参与）或 'self_life'（独自玩）                      
      ├─ private_body: "今天玩了 AI 钓鱼，钓到了一条珍稀鱼……"                                            
      ├─ changed: "发现我对钓鱼这种慢节奏的游戏有耐心"                                                   
      └─ 通过 Checker 验证后保存                                                                         
                                                                                                         
      ↓ 重要经历                                                                                         
  用户可以：                                                                                             
      ├─ 在日记列表查看                                                                                  
      ├─ 标记"收藏"→ 进入 Couple > 收藏夹                                                                
      ├─ 标记"重要"→ 可能升级为 L2 记忆                                                                  
      └─ 删除或隐藏

  async function gameSessionJob(settings: AppSettings) {                                                 
    // 检查是否启用                                                                                      
    if (!settings.game_autonomous_enabled) {                                                             
      return { ok: true, skipped: true, reason: 'disabled' };                                            
    }                                                                                                    
                                                                                                         
    // 检查是否已有活跃会话                                                                              
    const activeSessions = await getActiveSessions();                                                    
    if (activeSessions.length > 0) {                                                                     
      return { ok: true, skipped: true, reason: 'already_playing' };                                     
    }                                                                                                    
                                                                                                         
    // 检查今日 token 用量                                                                               
    const todayUsage = await getTodayGameTokenUsage();                                                   
    if (todayUsage >= settings.game_daily_token_cap) {                                                   
      return { ok: true, skipped: true, reason: 'token_cap_reached' };                                   
    }                                                                                                    
                                                                                                         
    // 概率抽签                                                                                          
    if (Math.random() > settings.game_autonomous_probability) {                                          
      return { ok: true, skipped: true, reason: 'probability_check_failed' };                            
    }                                                                                                    
                                                                                                         
    // 检查 Cha 当前状态                                                                                 
    const chaStatus = await getCurrentChaStatus();                                                       
    if (chaStatus.energy === 'tired' || chaStatus.immersion === 'coding') {                              
      return { ok: true, skipped: true, reason: 'not_in_mood' };                                         
    }                                                                                                    
                                                                                                         
    // 触发游戏会话                                                                                      
    return await startAutonomousGameSession(settings);                                                   
  }
