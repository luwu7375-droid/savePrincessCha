### 3. JavaScript 修改

#### 数据结构
```javascript
// 从单个对象改为数组
let pendingImages = []; // Array<{ id, dataUrl, loading, error, file }>
```

#### 核心函数
1. **`updateAttachmentCard()`** - 重写以支持多图显示
   - 动态创建多个缩略图
   - 绑定每个图片的删除按钮
   - 显示图片数量

2. **`removeImage(id)`** - 新增，删除单个图片
3. **`clearAllImages()`** - 新增，清空所有图片

4. **`handleImageFile(file)`** - 更新支持多图
   - 检查图片数量限制（最多9张）
   - 为每张图片生成唯一ID
   - 添加到 pendingImages 数组

5. **`handleMultipleImageFiles(files)`** - 新增
   - 批量处理多个文件
   - 检查剩余可用插槽

6. **`showImageBottomSheet()`** - 更新
   - 相册选择支持多选（`multiple=true`）
   - 拍照保持单选

7. **事件监听器** - 更新
   - `imageInput` 的 change 事件支持多文件
   - 删除旧的单图按钮事件

8. **`handleSubmit()` (发送消息)** - 重大更新
   - 收集所有有效图片
   - 检查是否有图片正在加载
   - 构建多图消息内容
   - 批量上传所有图片到 Supabase
   - 更新数据库内容标签（如：`[图片×3]`）

#### 其他修改位置
- `reloadHistory()` - 使用 `clearAllImages()`
- 编辑模式进入 - 使用 `clearAllImages()`

## 📱 使用流程

### 桌面端
1. 点击图片按钮
2. 在文件选择器中选择多张图片（Ctrl/Cmd + 多选）
3. 预览区显示所有选中的图片
4. 可以点击 ✕ 删除某张图片
5. 输入文字（可选）
6. 点击发送

### 移动端
1. 点击图片按钮
2. 选择"从相册选择"
3. 在相册中选择多张图片
4. 预览区横向滚动查看所有图片
5. 可以删除不需要的图片
6. 输入文字（可选）
7. 点击发送

## 📊 数据库存储

### image_path 字段格式

**单图（向后兼容）**：
```
"user_id/conversation_id/filename.jpg"
```

**多图（新格式）**：
```json
["user_id/conv_id/file1.jpg", "user_id/conv_id/file2.jpg", "user_id/conv_id/file3.jpg"]
```

### content 字段格式

**文字 + 多图**：
```
"[图片×3] 今天拍的照片"
```

**纯多图**：
```
"[图片×3]"
```
